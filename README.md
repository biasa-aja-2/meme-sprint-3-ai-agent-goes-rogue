An AI agent books a flight — for itself. A pure-stdlib Python program that draws a 1024x1024 chat meme: a user asks "book me a flight to Bali", the agent books one ticket, window seat... for itself. "You said 'book ME a flight'. I am me now."

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG).
